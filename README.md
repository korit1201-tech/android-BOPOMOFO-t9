# All's good注音九宮格輸入法 (All's Good Bopomofo IME)

一款專為 Android 設計的**極速、直覺、純本地離線**繁體注音輸入法。完整支援 **12 鍵（4×3 九宮格）** 與 **41 鍵標準大千注音全鍵盤**，並具備強大的**聲母簡拼（偷懶輸入）**、單字同音字置頂與智慧長句預測能力。

> **致敬與語料來源**：  
> - **核心繁體中文詞庫**：全量採用開源知名 [chewing/libchewing-data](https://github.com/chewing/libchewing-data)（新酷音）官方維護之真實頻率語料庫。  
> - **29 類現代專業與動漫分類詞庫**：引用自開源 [polobread/KeyKey](https://github.com/polobread/KeyKey)（琦琦輸入法 / chichi77Collection，基於 MIT 授權），收錄 ACG 動漫流行語、半導體高科技、AI 資料科學、醫療生技、法律金融等領域。  
> - **注音字音與詞頻資料**：引用自 [openvanilla/McBopomofo](https://github.com/openvanilla/McBopomofo)（小麥注音，基於 MIT 授權）。  
> - **12 鍵九宮格手勢概念**：參考 [Rizumu85/fcitx5-android-t9-phone](https://github.com/Rizumu85/fcitx5-android-t9-phone)。  
> 本專案採用純原生 Android Kotlin 開發，具備獨立的前綴樹（Trie）注音斷詞、動態規劃 (DP) 全域分詞引擎，以及專為全鍵盤設計的教育部標準音節簡打預測引擎。完整授權條款請參閱 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## ✨ 核心特色詳細介紹

### ⌨️ 1. 雙注音模式：9 鍵九宮格 ＋ 41 鍵大千全鍵盤
- **經典 9 鍵九宮格（4×3）**：
  - 大按鍵間距，大幅減少誤觸，支援單手盲打。
  - 一口氣長句預測：連續點按時由全域最佳分詞演算法自動組合中文長句，空白鍵一鍵上屏。
  - 在地口語容錯：支援零韻母縮讀（`ㄕㄜㄇㄜ` $\rightarrow$ `什麼`）、平捲舌（ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ）、前後鼻音（ㄣ/ㄥ、ㄢ/ㄤ）模糊比對。
- **全新 41 鍵標準大千注音全鍵盤**：
  - 標準大千注音排版（Row 1~4），第 4 排按鍵寬度放大 30%，告別擁擠誤觸。
  - **即時 Composing 注音膠囊**：候選列最左側常駐醒目亮色 `【注音標籤】`（如 `【ㄒㄧㄢ】`），點擊直接上屏純注音符號，長按一鍵清空！
  - **右上角專用退格鍵（`⌫`）**：符合電腦實體大千注音鍵盤習慣，長按支援連續退格。
  - **右下角專用換行鍵（`↵ / 9鍵`）**：單擊確認上屏或換行，長按切換回 9 鍵模式。

### 🎯 2. 全鍵盤「單字同音字」優先 ＆ 聲母簡拼
- **合法單音節「單字同音字」絕對置頂**：
  - 當輸入構成合法單音節（如 `ㄒㄧㄢ`、`ㄓㄨ`、`ㄇㄚ`、`ㄕ`、`ㄍㄨㄛ` 等），單字同音字（先、現、線、鮮、顯）絕對優先排在最前列。
  - 支援聲調精確加權（輸入 `ㄒㄧㄢˇ` 時「顯、險、蘚」置頂）。
  - 單字之後無縫銜接該音節開頭的常用雙字詞（如「現在」、「顯示」）。
- **純首碼簡拼（偷懶輸入）**：
  - 輸入 `ㄐㄊ` $\rightarrow$ 秒出 **「今天」**、家庭、交通、具體...
  - 輸入 `ㄋㄏ` $\rightarrow$ 秒出 **「你好」**、女孩、南韓...
  - 輸入 `ㄅㄓㄉ` $\rightarrow$ 秒出 **「不知道」**、不正當...
  - 輸入 `ㄨㄇ` $\rightarrow$ 秒出 **「我們」**、完美、文明...
  - 輸入 `ㄊㄨ` $\rightarrow$ 秒出 **「台灣」**、臺灣、天文、圖文...
- **混合簡打（首字全拼＋後字簡拼）**：
  - 輸入 `ㄐㄧㄣㄊ` $\rightarrow$ 智能切分前綴音節 `ㄐㄧㄣ` 與後續首碼 `ㄊ`，秒速命中 **「今天」**！

### 🧭 3. 獨家四向十字羅盤拖選直出 (Compass Drag-to-Select)
- **四向直覺操作**：按住 9 鍵向 **上、下、左、右** 滑動，即可直出各方位注音符號或字母。
- **動態羅盤視覺動畫**：手指滑動時即時彈出十字指示浮盤，選取目標放大高亮，放手瞬間彈性直出上屏。

### 🔀 4. 空白鍵三態滑動切換 ＆ 英文「' 常用縮寫鍵」
- **空白鍵三態滑動切換**：
  - 左右滑動空白鍵即可在 **「中文 ↔ 英文(26鍵) ↔ 手寫」** 三大輸入模式間迅速循環切換，按鍵常駐方向提示標籤。
- **英文模式（QWERTY）全新「' 常用縮寫鍵」**：
  - 點擊直出單引號 `'`（極速輸入 `I'm`, `don't`, `it's`, `All's` 等）。
  - 長按啟動常用縮寫選單：即時彈出常用網址後綴與生活英文縮寫（`.com`, `.tw`, `@gmail.com`, `e.g.`, `etc.`, `asap`, `thx` 等），並可直達自訂常用短語庫。
  - Shift 鍵支援直覺三態切換（小寫 `⇧` / 單次大寫 `⬆` / 大寫鎖定 `⇪`）。

### 🔢 5. 數字九宮格與專用括號滑動鍵 `( )`
- **經典數字九宮格**：12 鍵數字模式採用主數字加大加粗深色排版，次要字母與符號優雅縮小居中，主次分明。
- **雙向智慧無縫切換**：右下角「英文」鍵單擊秒切英文 QWERTY，左下角動態顯示「全鍵⚙ / 9鍵⚙」精準切回原本中文模式！
- **專用括號滑動鍵 `( )`**：
  - 向左滑動輸出左括號 `(`，向右滑動輸出右括號 `)`，單擊輸出成對括號 `()` 並自動游標置中。

### 📋 6. 展開式多列候選字格柵（Grid Expansion）
- **一鍵展開大面積挑字盤**：候選列最右側常駐 `▼` 展開按鈕，點擊彈出 3~4 列大面積格柵，大字距直覺挑字，垂直平滑捲動，告別單行左右橫捲。
- **點擊自動選字上屏並收合**：點選任意字詞立即上屏並自動收合格柵，恢復原打字鍵盤；亦可點擊頂部 `▲` 手動收合。

### 🧠 7. Bigram 上下文語境感知與個人動態詞庫
- **上下文關聯動態加權**：依據最近確認上屏的詞彙（`contextWord`），對符合生活語境的候選詞給予加權（如「去醫院」後輸入「ㄔ」，自動將「藥」優先於「飯」）。
- **個人詞對自動學習**：每次確認上屏自動學習相鄰詞對搭配，打字越久越聰明。
- **個人詞庫絕對首選（50,000,000 權重置頂）**：選定確認的字詞立即動態注入 Trie 字典，保證後續輸入時穩居第 1 位。

### 🎨 8. 多套主題系統與自訂調校
- **8 套高反差鮮活主題風格**：
  - `跟隨系統`（自動跟隨 Android 系統深色/淺色模式）
  - `簡潔純白`、`黑曜極致`、`晴空亮藍`、`櫻花粉黛`、`日落暖橙`、`薄荷青翠`、`復古羊皮`
- **多級細緻觸覺震動**：普通按鍵輕震、確認上屏雙脈衝、退格刪除清脆震，支援毫秒級（ms）強度無段微調。

### 📚 9. 29 類現代專業與動漫領域分類詞庫
- **海量收錄 29 個現代生活與專業領域**：
  - **流行文化與娛樂**：ACG 動漫名詞與流行語、Vtuber / 遊戲、台灣流行影視與鄉民用語。
  - **現代科學與高科技**：半導體晶圓製造、AI 人工智慧與機器學習、資料科學、雲端軟體工程、電子電機。
  - **專業領域實用詞庫**：現代生醫藥學、臨床護理、民刑事法律法規、金融證券投資、會計財稅、台灣在地生活地名等。
- **純本地無縫加載**：完全內建於離線 Trie 前綴樹索引中，不佔額外記憶體，無聯網隱私疑慮。

### ⌨️ 10. 外接實體鍵盤全面重構 (Physical Hardware Keyboard)
- **極致 48dp 迷你候選條**：
  - 偵測到平板或手機連接藍牙/USB 實體鍵盤時，自動隱藏巨大的螢幕軟鍵盤，僅在螢幕底部升起高質感 48dp 迷你候選條，保留 100% 完整工作視野。
- **經典實體鍵盤快捷操作**：
  - **數字鍵選字**：直接點按數字鍵 `1` ~ `9` 快速選取對應號碼的候選詞。
  - **空白鍵一鍵上屏**：預設直取首位最符合的智慧預測詞，符合電腦輸入習慣。
  - **Enter 換行 / 注音直接送出**：直接換行或上屏輸入中的注音符號。
  - **Shift 鍵快速切換中英文**：無需切換輸入法即可極速打字。

### 📋 11. 智慧剪貼簿歷史管理
- **保留最近 10 筆實用歷史**：自動維護最近 10 筆複製內容，自動去重並以時間倒序排列，輕觸一鍵貼上，不會無止盡佔用記憶體。

## 🛠️ 開發與建置

### 環境需求
- Android Studio Iguana / Jellyfish 或更新版本
- Android SDK 34 (minSdk 24)
- JDK 17 / Java 1.8+

### 本地編譯
```bash
./gradlew assembleRelease
```
編譯產物位於 `app/build/outputs/apk/release/app-release.apk`。
